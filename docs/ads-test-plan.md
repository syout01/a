# 広告テスト計画（DigLead LP）

目的：**LP に広告から人を流したとき、いくらで 1 件の相談が取れるか**を 2 週間・小額で確かめる。
判断に使う数字は「相談 1 件あたりの広告費（CPA）」と「相談の質（名刺規模・展示会予定の有無）」の 2 つ。

## 1. 事前準備（広告を出す前に必ず）

| # | やること | 状態 |
| --- | --- | --- |
| 1 | LP に相談フォームとサンクスページを置く | 済（`/lp.html` `/lp-thanks.html`） |
| 2 | Google タグマネージャー（GTM）のコンテナを作り、ID を Render の `GTM_ID` に設定 | 要作業 |
| 3 | GTM に GA4 と Google 広告のコンバージョンタグを入れる。コンバージョン条件＝「ページ URL が `/lp-thanks.html` を含む」 | 要作業 |
| 4 | プライバシーポリシーの URL を確認（LP は `https://synapse-work.com/privacy` にリンクしている。存在しなければ差し替え） | 要確認 |
| 5 | Slack 通知（`SLACK_WEBHOOK_URL`）を設定し、テスト送信が届くか確認 | 要作業 |
| 6 | 自分で LP から 1 件テスト送信 → 設定画面に出る・サンクスページに飛ぶ・Google 広告側でコンバージョンが記録されるか確認 | 要作業 |

GTM を使うのは、後から Meta ピクセルや別の計測を足すときにサーバーを触らなくて済むためです。

## 2. 媒体の選び方

| 媒体 | 向き | 判断 |
| --- | --- | --- |
| **Google 検索広告** | 「展示会 フォロー」「展示会 名刺 営業」など、今まさに困って検索している人に出せる | **最初のテストはこれ 1 本** |
| Meta（Facebook / Instagram） | 興味関心で広く当てる。BtoB の担当者に届くが、検索より温度が低い | 検索で CPA が見えてから |
| LinkedIn | 役職ターゲティングが強いがクリック単価が高い（数百〜千円台） | 単価が合うか要検討 |
| 展示会メディア・出展社リストへの DM | 広告ではないが、同じ LP に誘導して効果比較できる | 並行実施を推奨 |

検索広告から始める理由は、意図が明確な人だけに出せて、少額でも「取れる／取れない」がはっきり出るからです。

## 3. Google 検索広告の設計

### キャンペーン
- 種類：検索、地域：日本、言語：日本語、配信：検索ネットワークのみ（ディスプレイ拡張はオフ）
- 予算：**1 日 3,000〜5,000 円、14 日間**（合計 4〜7 万円）
- 入札：最初の 1 週間は「クリック数の最大化」（上限 CPC 300 円）、コンバージョンが 5 件たまったら「コンバージョン数の最大化」に切替
- 曜日・時間：平日 8〜20 時に絞る（BtoB の検索が集中する時間帯）

### 広告グループとキーワード（フレーズ一致・完全一致で開始）

| グループ | キーワード例 |
| --- | --- |
| 展示会フォロー | "展示会 フォロー", "展示会 後 フォロー", "展示会 アフターフォロー", [展示会 フォロー 代行] |
| 展示会 名刺 | "展示会 名刺 営業", "展示会 名刺 フォロー", "展示会 名刺 管理", "展示会 リード 管理" |
| 展示会 アポ | "展示会 アポ", "展示会 商談化", "展示会 リード 商談", [展示会 テレアポ 代行] |
| 展示会 効果 | "展示会 効果 出ない", "展示会 費用対効果", "展示会 成果" |

除外キーワード：求人, 採用, バイト, 派遣, 設営, 施工, ブース デザイン, 装飾, コンパニオン, 無料 テンプレート, エクセル テンプレート, 書き方

### 広告文（レスポンシブ検索広告）

見出し（30 文字以内、15 本まで登録。以下から選ぶ）
1. 展示会の名刺を翌営業日から商談に
2. 展示会フォロー特化 DigLead
3. 名刺リストを取り込み即日で優先順位
4. 通常の新規開拓の6〜11倍のアポ率
5. 閉会翌営業日から架電を開始
6. 1コール500円から・最低100コール
7. 展示会後2週間で全件フォロー
8. 決裁者から順に架電する仕組み
9. 不通・再コールの取りこぼしゼロ
10. 進捗はスプレッドシートで共有
11. 展示会リードの二次回収まで対応
12. AIで個社カルテ・人が電話

説明文（90 文字以内、4 本まで）
1. 展示会の来場者リストを取り込んだ瞬間に決裁関与×温度で振り分け。翌営業日から決裁者順に架電し、2週間で全件クローズ。進捗はシートで共有します。
2. 「遅い・浅い・続かない」展示会フォローを仕組みで解消。対コールのアポ率8.2〜14.3%（自社運用実測）。まずは名刺の規模と日程をご相談ください。
3. 1コール500円から。会期前のお申込みで閉会翌営業日に開始。AIが個社カルテと文面を作り、人が電話とトリアージを担当します。
4. 展示会のあとのフォローが回らない企業向け。名刺400枚を翌週から架電、不通は理由別に再アプローチ。無料でご相談いただけます。

最終ページ URL：`https://diglead.onrender.com/lp.html`（独自ドメインにしたら差し替え）
URL パラメータ：`utm_source=google&utm_medium=cpc&utm_campaign=expo_followup_test&utm_term={keyword}`
サイトリンク：できること（`#flow`）、実績（`#results` ※アンカー追加要）、料金（`#plans`）、相談する（`#contact`）

## 4. 見る数字と判断基準（2 週間後）

| 指標 | 目安 | 判断 |
| --- | --- | --- |
| クリック率（CTR） | 3% 以上 | 2% 未満なら広告文かキーワードが合っていない |
| クリック単価（CPC） | 150〜300 円 | 400 円超なら入札上限を下げ、キーワードを絞る |
| LP のフォーム到達率 | 20% 以上（`#contact` までスクロール） | 低ければヒーローの訴求を変える |
| 相談率（CVR） | 3〜5% | 1% 未満なら LP のフォーム位置・必須項目を減らす |
| 相談 1 件あたり費用（CPA） | 1〜2 万円以内 | 3 万円超なら媒体を変えるか LP を作り直す |
| 相談の質 | 名刺 100 枚以上・展示会予定ありが半数以上 | 質が低ければキーワードを「代行」「アポ」寄りに |

DigLead のライトプランは 100 コールで 5 万円なので、CPA 2 万円以内で受注率 3 割なら回ります。

## 5. 週次でやること

- 月曜：検索語句レポートを見て、関係ない語句を除外に追加。CPA の悪いキーワードを停止
- 水曜：相談の中身（設定画面の一覧）を確認し、質のよい相談の流入元（utm_term）に予算を寄せる
- 金曜：LP の改善を 1 か所だけ入れる（見出し、フォームの位置、必須項目のどれか 1 つ）

## 6. 2 週間後の次の一手

- CPA が目安内：予算を 2 倍にして 1 か月継続。Meta でリターゲティング（LP 訪問者に再表示）を追加
- CPA が目安外・クリックは取れている：LP の問題。ヒーローの訴求とフォームを差し替えて再テスト
- クリック自体が少ない：検索ボリュームが小さい。展示会主催者の出展社リストへの DM やセミナー連動に切替
